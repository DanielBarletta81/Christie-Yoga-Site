# Christie Yoga & Ayurvedic Wellness Site

A minimal, peaceful website for yoga and ayurvedic wellness built with Next.js and React.

## Features

- Peaceful hero image section
- Image carousel for wellness photography
- Two-card split section for Ayurvedic information
- WordPress CMS integration
- Optimized for Vercel deployment

## Getting Started

1. Install dependencies:
```bash
npm install
```

2. Set up environment variables:
   - Copy `.env.example` to `.env.local`
   - Add your WordPress API URL

3. Run the development server:
```bash
npm run dev
```

4. Open [http://localhost:3000](http://localhost:3000)

## WordPress Setup

Configure your WordPress site with the REST API enabled. The site will fetch content from your WordPress backend.

## Deployment

Deploy to Vercel with one click or using the Vercel CLI:
```bash
vercel
```

Make sure to add your environment variables in the Vercel dashboard.
