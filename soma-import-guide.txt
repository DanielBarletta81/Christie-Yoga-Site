FILES INCLUDED
- chakras.csv
- sounds.csv
- practices.csv
- rituals.csv
- guides.csv

IMPORT ORDER (RECOMMENDED)
1) chakras.csv  -> Post Type: Chakra
2) practices.csv -> Post Type: Practice
3) rituals.csv  -> Post Type: Ritual
4) guides.csv   -> Post Type: Guide
5) sounds.csv   -> Post Type: Sound

GENERAL SETTINGS (ALL IMPORTS)
- Update existing posts: YES
- Set Status: publish (already in CSV)
- Unique Identifier:
  * Sound: audio_url
  * Chakra: post_title
  * Practice: post_title
  * Ritual: post_title
  * Guide: post_title
