# Image Assets

Place your images in this directory:

## Required Images:

### Hero Section
- `hero-background.jpg` - Peaceful yoga or nature scene for the hero section

### Carousel (Mono/Black & White images)
- `carousel-1.jpg` - Yoga practice image
- `carousel-2.jpg` - Meditation image  
- `carousel-3.jpg` - Ayurvedic herbs/ingredients
- `carousel-4.jpg` - Wellness/lifestyle image

### Split Section Cards
- `ayurveda.jpg` - Image representing Ayurvedic diet
- `wellness.jpg` - Image representing holistic wellness

## Image Recommendations:
- Use high-quality images (at least 1920px wide for hero)
- Carousel images should be similar aspect ratio (landscape preferred)
- Consider using black & white or monochrome images for elegant, minimal aesthetic
- Optimize images before upload (use tools like TinyPNG or ImageOptim)
